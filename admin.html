Hostinger Production Deployment Guide

Instructions for deploying TAVRO Studio to Hostinger and configuring tavrostudio.in.

Deployment Architecture

TAVRO Studio is built with native Node.js (zero external dependencies) and standard modern frontend assets. It can be hosted on:

  • Hostinger Cloud / VPS Hosting (Recommended for maximum speed, Node.js daemon support, and automated Git hooks).
  • Hostinger Web Hosting (with Node.js selector) via cPanel / hPanel.

Quick Deployment Steps

  1. Upload Project Files: Upload the freefall-portfolio-code-main folder to your Hostinger server public root or app directory via Git or File Manager.
  2. Configure Node.js Application in hPanel:
    • Application Root: public_html (or custom path)
    • Application Startup File: server.js
    • Node.js Version: 18.x or 20.x or 22.x
  3. Environment Variables (Optional):
    • PORT: Assigned automatically by Hostinger, defaults to 8000.
    • ADMIN_PASSWORD: Your custom secure master password for this admin panel.
  4. Map Custom Domain (tavrostudio.in): Once purchased, assign the domain to this website in Hostinger DNS and enable Free Let's Encrypt SSL.
